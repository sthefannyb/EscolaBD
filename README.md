# EscolaBD
Repositório criado para desenvolver o produto de software para fins de matrículas escolares em específico para escolas privadas.

## contexto
Sistema para gerenciar o cadastro de matrículas da escola, assim, facilitando o cadastramento de discentes e também de servidores, deixando organizado para garantir uma gestão centralizada, segura e totalmente integrada. 

- cadastra discente
- cadastra servidores
- organiza o sistema por ano de matrícula, data de nascimento ou código de registro
- facilita o acesso a informaç~çoes pessoais de servidores e alunos
