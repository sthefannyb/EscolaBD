# EscolaBD
Repositório criado para desenvolver um produto de software focado em matrículas escolares, projetado especificamente para atender às demandas de escolas privadas e institutos.

## Contexto
O EscolaBD é um sistema de gerenciamento de cadastros, matrículas e fluxos acadêmicos. Ele foi idealizado para simplificar o dia a dia da secretaria e da gestão de instituições de ensino, facilitando o cadastramento de discentes (alunos) e servidores (professores, tutores e corpo administrativo).
O objetivo principal é garantir uma gestão centralizada, segura e totalmente integrada das informações da comunidade escolar, adaptando-se tanto ao modelo de ensino básico quanto ao formato modular de institutos.

- Cadastro de Discentes: Controle completo do ciclo de vida do aluno na instituição (matrículas, turmas e históricos).
- Cadastro de Servidores: Registro detalhado de funcionários, cargos, especialidades e departamentos.
- Busca e Organização Flexível
- Filtre e ordene o sistema facilmente por:
  - Ano ou período de matrícula
  - Data de nascimento
  - Código de registro único (RA, Matrícula ou SIAPE)
- Acesso Rápido a Informações Pessoais: Consulta facilitada, segura e centralizada de dados de servidores e alunos.
